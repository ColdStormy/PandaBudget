# Bundled fonts

The Bamboo design system uses two open-source typefaces, both licensed under
the SIL Open Font License 1.1 (full texts alongside the fonts).

| Family | Files | Use | Copyright |
| --- | --- | --- | --- |
| PT Serif | `PTSerif-Regular.ttf`, `PTSerif-Bold.ttf` | Structure: page titles, section headings, the large balance | © 2010 ParaType Ltd. |
| Figtree | `Figtree-Regular.ttf`, `Figtree-Medium.ttf`, `Figtree-SemiBold.ttf` | Everything you read, count or tap | © 2022 The Figtree Project Authors |

Both were taken from Google Fonts as static instances so that weights resolve
the same on every platform (variable fonts render inconsistently on desktop).
